# FANCIVE — Editorial Fashion Website

에디토리얼 감성의 패션 브랜드 웹사이트. 잡지 스프레드 형식의 레이아웃, 정밀한 픽셀 좌표 기반 디자인 스펙, 그리고 페이지 전환 애니메이션을 중심으로 제작되었습니다.

---

## 페이지 구성

| 페이지 | 파일 | 설명 |
|---|---|---|
| 메인 (인트로 + 스프레드) | `index.html` / `script.js` / `style.css` | 브랜드 첫 인상, 인트로 애니메이션 후 에디토리얼 스프레드 |
| 컬렉션 | `collection.html` | 룩북 그리드, 호버 이펙트 |
| 룩 디테일 | `look-detail.html` | 5-이미지 에디토리얼 스프레드, 세로 메뉴, 하단 인덱스 |
| 어바웃 | `about.html` | 브랜드 소개, 페이드인 전환 |
| 아카이브 | `archive.html` | 시즌 드럼 (스크롤/클릭 인터랙션) |

---

## 제작 흐름

### 1단계 — 기반 구조 (2026-05-22)

`Initial commit`으로 프로젝트 시작. `design-spec.txt`에 정의된 픽셀 좌표 기반으로 메인 스프레드를 구성했으며, 각 요소(로고, 메인 이미지, 디테일 이미지, 오브제 등)의 `x / y / w / h` 값을 CSS에 그대로 반영했습니다.

초기에는 좌표 오차를 잡는 픽스 작업이 집중적으로 이루어졌습니다.

- `right_item` 위치 반복 조정 (overlap 문제 해소)
- `right_object` 회전 제거
- `left_mood1_text` 간격 및 너비 수정
- 스케일 래퍼, 페이퍼 프레임, 어두운 배경, 스프레드 센터링 기준 확립

### 2단계 — 인터랙션 & 인트로 (2026-05-22 ~ 05-23)

스프레드 요소에 진입 애니메이션, 플로팅, 드리프트, 호버 이펙트를 추가했습니다.

인트로 흐름은 여러 번 재설계됐습니다:

1. 스타킹 풀스크린 → 스프레드 리빌
2. 에디토리얼 콜라주 → 스프레드 조립 애니메이션
3. 9개 이미지 콜라주 + clip-path wipe 퇴장
4. blur-to-focus 리빌로 교체
5. 로딩 스크린 추가 및 스프레드 인터랙션 정제

### 3단계 — 서브페이지 확장 (2026-05-25 ~ 05-27)

컬렉션, 룩 디테일, 어바웃, 아카이브 페이지를 순차적으로 추가했습니다.

- **컬렉션 & 룩 디테일**: 에디토리얼 레이아웃, ghost year 텍스트, 타이포그래피
- **어바웃 & 아카이브**: 다크 외곽 프레임, 이웃 요소 페이드 호버
- **룩 디테일 재설계**: 5-이미지 스프레드를 스펙 좌표 기준으로 재구축, 인덱스를 하단으로 이동, 세로 메뉴 추가

### 4단계 — 페이지 전환 & 폴리시 (2026-05-28 ~ 05-29)

- 페이지 전환: 다크 오버레이 → blur-to-focus 진입 흐름 구축
- 아카이브: 시즌 드럼 (스크롤/클릭으로 계절 전환하는 인터랙티브 드럼 UI)
- 인트로: 텍스트 워드마크 → 로고 이미지로 교체
- 아카이브 gather 애니메이션, 룩 디테일 헤더/인덱스, 인트로 지속성 개선

### 5단계 — 성능 최적화 (2026-05-30 ~ 05-31)

이미지 전체를 PNG → WebP로 변환하며 용량을 대폭 줄였습니다.

| 대상 | 감소율 |
|---|---|
| `collection_sub` 이미지 | 95% |
| `about` 이미지 | 96% |
| 전체 나머지 이미지 | 93% |
| `intro_logo.webp` | 무손실 재출력 |

### 6단계 — 버그 픽스 (2026-05-30)

- 룩 디테일 페이지 이미지 pop-in 방지
- 아카이브 `ar_digit_0` 위치 오류 반복 수정 (obj1 뒤에 숨는 문제 해소)
- ABOUT / ARCHIVE 네비게이션 cursor pointer 누락 수정
- 인트로 skip 로직: `localStorage` → `sessionStorage` 전환 (탭 종료 시 리셋)
- 서브페이지에서 돌아올 때 항상 인트로 스킵 처리
- 호버 이펙트가 인트로 스킵 경로에서 사라지는 문제 수정
- 햄버거 메뉴 텍스트 클리핑 → 너비 110px으로 수정
- 로드 퍼포먼스 및 애니메이션 타이밍 전반 조정

### 7단계 — 타이포그래피 & 전환 폴리시 (2026-06-01, PR #1 & #2)

**PR #1** — 서브페이지 전환 오버레이 색상 변경 (다크 → 서브페이지 배경색), About 페이지 페이드인 딜레이 추가로 전환 자연스럽게 개선.

**PR #2** — 서브페이지 타이포그래피 전반 폴리시, 컬렉션 레이아웃 정제.

## 기술 스택

- **Vanilla HTML / CSS / JS** — 프레임워크 없이 순수 구현
- **WebP** — 이미지 최적화
- **CSS 애니메이션 & 트랜지션** — 진입/퇴장/플로팅/호버 전부 CSS 기반
- **SessionStorage** — 인트로 노출 여부 세션 단위 관리
- `design-spec.txt` — 픽셀 좌표 기반 디자인 스펙 문서
